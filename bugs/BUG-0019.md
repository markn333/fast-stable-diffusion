# BUG-0019: No module named 'pytorch_lightning.utilities.distributed'
- Date: 2026-08-24
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'pytorch_lightning.utilities.distributed'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `shared.py` → `sd_models_types.py` → `ldm/models/diffusion/ddpm.py` → `from pytorch_lightning.utilities.distributed import rank_zero_only`

## Root Cause

`pytorch_lightning` v2.x removed `utilities.distributed`. The `rank_zero_only` function was moved to `pytorch_lightning.utilities.rank_zero`. The `ddpm.py` file on Google Drive contains the old import path from pytorch_lightning v1.x.

## Fix

Added a `sed` patch in the Requirements cell to update the import path in `ddpm.py` on Google Drive:

```python
!sed -i 's@from pytorch_lightning.utilities.distributed import rank_zero_only@from pytorch_lightning.utilities.rank_zero import rank_zero_only@g' \
    /content/gdrive/$mainpth/sd/stablediffusion/ldm/models/diffusion/ddpm.py
```

## Changed Files
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

## Prevention

Each `pytorch_lightning` major version update may move or remove submodules. Applying the patch at runtime ensures it reapplies after any library update.
