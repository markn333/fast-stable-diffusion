# BUG-0022: ModuleNotFoundError: No module named 'clip'
- Date: 2026-08-25
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'clip'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `processing.py` → `sd_hijack.py` → `sd_hijack_optimizations.py` → `sd_samplers.py` → `sd_samplers_kdiffusion.py` → `k_diffusion/__init__.py` → `k_diffusion/evaluation.py` → `import clip`

## Root Cause

OpenAI CLIP (`openai-clip`) was removed from Colab's pre-installed packages. This package is a dependency of k-diffusion (bundled with the Stable Diffusion repo on Google Drive), not listed in the webui's `requirements.txt`.

## Fix

Added `openai-clip` to the Requirements cell:

```python
!pip install openai-clip -qq
```

- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

Any package removed from Colab's base image must be explicitly installed in the Requirements cell.
