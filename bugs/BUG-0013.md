# BUG-0013: ModuleNotFoundError: No module named 'pyngrok'
- Date: 2026-08-24
- Status: Resolved
- Severity: Medium

## Symptom

The notebook fails during import with:

```
ModuleNotFoundError: No module named 'pyngrok'
```

The `pyngrok` package is imported in the startup/tunnel cell but is no longer pre-installed in the Colab runtime.

## Root Cause

A Colab base image update removed `pyngrok` from the pre-installed packages. The notebook relied on it being available without an explicit install step.

## Fix

Added `pyngrok` to the Requirements cell:

```python
!pip install pyngrok -qq
```

## Changed Files
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

## Prevention

Any package removed from Colab's base image must be explicitly installed in the Requirements cell.
