# BUG-0008: ComfyUI simpleeval missing + xformers version mismatch
- Date: 2026-04-30
- Status: Resolved
- Severity: Medium

## Symptom
ComfyUI startup log showed:
- `nodes_math.py IMPORT FAILED: No module named 'simpleeval'`
- `WARNING[XFORMERS]: xFormers was built for PyTorch 2.9.0+cu128 (you have 2.10.0+cu128)`

## Root Cause
- `simpleeval` package was not included in Requirements cell pip install line
- xformers stable release was still built for PyTorch 2.9, not 2.10

## Fix
- Added `simpleeval` to pip install line in Requirements cell
- Added xformers fix cell (same as AUTOMATIC1111) with `--pre` flag to install pre-release version compatible with PyTorch 2.10

## Commit
`c162ced`

## Prevention
Include `simpleeval` and keep xformers fix cell in both notebooks going forward.
