# BUG-0002: gdown v6 破壊的変更によるモデルダウンロード機能の停止リスク

- 報告日: 2026-04-27
- ステータス: 完了（短期対応済み）
- 重要度: 高

## 現象

gdown v6.0.0（2026年4月中旬リリース）に以下の破壊的変更が含まれており、
全3ノートブックのモデルダウンロード機能が停止するリスクがある。

| 削除された機能 | 影響ノートブック |
|---|---|
| `get_url_from_gdrive_confirmation`（v5で deprecated、v6で完全削除） | A1111, ComfyUI, DreamBooth |
| `gdown.download(..., fuzzy=True)` パラメータ削除 | A1111（L.380, 392, 441, 449）, ComfyUI（L.305, 317, 366, 374） |
| `!gdown --fuzzy ...` CLI フラグ削除 | A1111（L.332）, ComfyUI（L.270）, DreamBooth（L.370） |
| `!gdown --remaining-ok ...` CLI フラグ削除 | DreamBooth（L.495） |

## 原因

gdown が v6.0.0 で大規模リファクタリングを実施。Google Drive URLからの自動 ID 検出が
改善されたため `fuzzy` オプションが不要になり削除された。また内部ヘルパー関数
`get_url_from_gdrive_confirmation` も公開 API から除去された。

## 処置内容（短期対応）

各ノートブックのRequirementsセル（DreamBoothはDependenciesセル）に `pip install gdown==5.2.1 -qq` を追加し、v5系の最新安定版にピン留めした。

- 変更ファイル:
  - `fast_stable_diffusion_AUTOMATIC1111.ipynb`
  - `fast_stable_diffusion_ComfyUI.ipynb`
  - `fast-DreamBooth.ipynb`
- コミット: `822d26c` (fix: pin gdown==5.2.1 to prevent gdown v6 breaking changes)

## 再発防止策・今後の対応

短期対応（ピン留め）は恒久解決ではない。長期的には v6 対応として以下の修正が必要（T-009残タスク）：

1. `from gdown.download import get_url_from_gdrive_confirmation` を削除し、`get_name()` の gdrive 処理を `gdown.parse_url()` ベースに書き換え
2. `gdown.download(..., fuzzy=True)` → `fuzzy=True` を削除
3. `!gdown --fuzzy ...` → `--fuzzy` を削除
4. `!gdown --remaining-ok ...` → `--remaining-ok` を削除（DreamBooth）
