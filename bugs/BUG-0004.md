# BUG-0004: sd_disable_initialization.py で meta テンソルコピーエラー
- 報告日: 2026-04-29
- ステータス: 完了
- 重要度: 高

## 現象
モデル切り替え時（UI から別モデルを選択した際）に `load_state_dict` が失敗する。

```
RuntimeError: Error(s) in loading state_dict for DiffusionEngine:
    While copying the parameter named "...", an exception occurred :
    ('Cannot copy out of meta tensor; no data!',).
```

エラー箇所:
```
File ".../modules/sd_disable_initialization.py", line 221, in load_state_dict
    original(module, state_dict, strict=strict)
```

## 原因
PyTorch 2.10.0 の `torch.nn.Module.load_state_dict` が meta テンソル（実データなし）への値コピー（`assign=False` デフォルト動作）を明示的に拒否するようになった。

`sd_disable_initialization.py` は遅延初期化のために meta テンソルを使っており、モデルウェイトのロード時に `original(module, state_dict, strict=strict)` を呼ぶが、`assign=True` が渡されていないため全パラメータでコピーエラーが発生する。

`assign=True` を渡すことで「コピーではなく直接割り当て」モードになり、meta テンソルからの制約を回避できる。

## 処置内容
Start セル (`PjzwxTkPSPHf`) に下記 sed パッチを追加:

```bash
!sed -i 's@original(module, state_dict, strict=strict)@original(module, state_dict, strict=strict, assign=True)@g' \
  /content/gdrive/$mainpth/sd/stable-diffusion-w$blsaphemy/modules/sd_disable_initialization.py
```

変更ファイル: `fast_stable_diffusion_AUTOMATIC1111.ipynb`（Start セル）

## 再発防止策
- PyTorch のメジャーバージョンアップ時は `load_state_dict` 周辺の挙動変更を確認する
- `assign=True` は PyTorch 2.0 以降で利用可能。より古いバージョンとの後方互換性は不要（Colab は常に最新版）
