# BUG-0009: ComfyUI URL not accessible (tunnel + timing issues)
- Date: 2026-04-30
- Status: Resolved
- Severity: High

## Symptom
Multiple URL access failures:
- `eval_js` raised `MessageError: TypeError: Failed to fetch`
- cloudflared tunnel caused `lockdown-install.js` SES injection → blank page
- localhost.run WebSocket broken → ComfyUI logo spinning indefinitely
- pinggy tunnel URL shown before ComfyUI HTTP server was ready → `ERR_EMPTY_RESPONSE`

## Root Cause
1. `eval_js` is unreliable when Colab browser connection is unstable
2. cloudflared injects SES JavaScript lockdown that breaks ComfyUI frontend
3. localhost.run does not reliably forward WebSocket connections
4. URL was shown before ComfyUI's HTTP server started accepting connections
5. Python stdout buffering caused `tee` log monitoring to read stale cached log

## Fix
- Switched from `eval_js` → pinggy.io SSH tunnel (WebSocket-compatible, no JS injection)
- Rewrote Start cell to run ComfyUI as `subprocess.Popen` and stream output line-by-line
- URL is now printed immediately after `"To see the GUI go to:"` appears in actual stdout
- Added `eval_js` as first-choice fallback with pinggy as second-choice
- Moved `pyngrok` import inside `if Ngrok_Token != "":` block to avoid `OSError 107`
