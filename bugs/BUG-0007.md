# BUG-0007: ComfyUI crashes with ModuleNotFoundError: No module named 'comfy_aimdo'
- Reported: 2026-04-30
- Status: Resolved
- Severity: High

## Symptom
ComfyUI Start cell crashes immediately after launch.

```
File "/content/gdrive/MyDrive/ComfyUI/main.py", line 34, in <module>
    import comfy_aimdo.control
ModuleNotFoundError: No module named 'comfy_aimdo'
```

## Root Cause
ComfyUI's `main.py` added a dependency on `comfy-aimdo` (PyPI package) for Dynamic VRAM
management support. The Requirements cell was installing an older set of packages that
did not include `comfy-aimdo`, causing an import error at startup.

## Fix
Added `comfy-aimdo` to the `pip install` line in the Requirements cell (`ZGV_5H4xrOSp`):

```bash
# Before
!pip install diffusers accelerate transformers av comfyui-frontend-package comfyui-workflow-templates alembic -U -qq

# After
!pip install diffusers accelerate transformers av comfyui-frontend-package comfyui-workflow-templates alembic comfy-aimdo -U -qq
```

Changed file: `fast_stable_diffusion_ComfyUI.ipynb` (Requirements cell)

## Prevention
- When ComfyUI is updated via `git pull` in the Install cell, check `requirements.txt`
  for new dependencies and keep the Requirements cell in sync
