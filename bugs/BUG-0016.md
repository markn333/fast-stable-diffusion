# BUG-0016: ModuleNotFoundError: No module named 'open_clip'
- Date: 2026-08-24
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'open_clip'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `paths.py` → `sgm` → `sgm/modules/encoders/modules.py` → `import open_clip`

## Root Cause

A Colab base image update removed `open_clip_torch` (which provides the `open_clip` module) from the pre-installed packages.

## Fix

Added `open_clip_torch` to the Requirements cell:

```python
!pip install pyngrok pytorch_lightning kornia open_clip_torch -qq
```
