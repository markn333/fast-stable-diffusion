# BUG-0006: ComfyUI crashes on start when Ngrok_Token is empty
- Reported: 2026-04-30
- Status: Resolved
- Severity: High

## Symptom
ComfyUI Start cell crashes immediately if `Ngrok_Token` is left blank.

```
PyngrokNgrokError: The ngrok process errored on start: authentication failed:
Usage of ngrok requires a verified account and authtoken.
ERR_NGROK_4018
```

## Root Cause
The original Start cell calls `ngrok.connect()` unconditionally, with no check for an empty `Ngrok_Token`.
The AUTOMATIC1111 notebook handles this correctly with an `if Ngrok_token != "":` guard,
but the ComfyUI notebook was missing this check entirely.

## Fix
Added an `if Ngrok_Token != "":` conditional to the Start cell:

- **With token**: connects via ngrok as before
- **Without token**: skips ngrok, prints Colab port forwarding instructions,
  and runs ComfyUI with `--listen --port 666` directly

Changed file: `fast_stable_diffusion_ComfyUI.ipynb` (Start cell)

## Prevention
- When porting patterns between notebooks, verify that all guard conditions are carried over
- The AUTOMATIC1111 ngrok guard pattern should be used as the reference for all notebooks
