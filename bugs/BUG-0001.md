# BUG-0001: xformers が PyTorch 2.10.0 で動作しない

- 報告日: 2026-04-27
- ステータス: 完了
- 重要度: 中

## 現象

`fast_stable_diffusion_AUTOMATIC1111.ipynb` の Start セル実行時に以下の警告・エラーが発生し、xformers が無効化されていた。

```
WARNING[XFORMERS]: xFormers can't load C++/CUDA extensions. xFormers was built for:
    PyTorch 2.9.0+cu128 (you have 2.10.0+cu128)
    Python  3.10.19 (you have 3.12.13)
*** Cannot import xformers
ImportError: /usr/local/lib/python3.12/dist-packages/xformers/flash_attn_3/_C.so:
  undefined symbol: _ZN3c104cuda29c10_cuda_check_implementationEiPKcS2_ib
```

xformers が無効のため `Doggettx` 最適化にフォールバックしており、速度・メモリ効率が低下していた。

## 原因

Google Colab が PyTorch を `2.9.0+cu128 → 2.10.0+cu128` に自動アップデートした。
インストール済みの xformers バイナリは旧バージョンの PyTorch 向けにビルドされており、バイナリ互換性がなくなった。

## 処置内容

Requirements セルの直後に **「Fix xformers」セル** を追加。
現在インストールされている PyTorch のバージョンに合った xformers を `pip install xformers --upgrade` で再インストールするよう修正した。

- 変更ファイル: `fast_stable_diffusion_AUTOMATIC1111.ipynb`
- コミット: `8308f00` (fix: reinstall xformers to match current PyTorch version on Colab)

## 再発防止策

- Colab が PyTorch をアップデートするたびに同様の問題が発生しうる
- 「Fix xformers」セルが毎回実行されることで自動的に追従できる
- PyTorch バージョンアップ後にエラーが出た場合は、まず xformers の再インストールを試みること
