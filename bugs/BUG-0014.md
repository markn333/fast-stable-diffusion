# BUG-0014: ModuleNotFoundError: No module named 'pytorch_lightning'
- Date: 2026-08-24
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'pytorch_lightning'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `import pytorch_lightning`

## Root Cause

A Colab base image update removed `pytorch_lightning` from the pre-installed packages. The notebook relied on it being available without an explicit install step.

## Fix

Added `pytorch_lightning` to the Requirements cell (combined with the existing `pyngrok` install line):

```python
!pip install pyngrok pytorch_lightning -qq
```

## Changed Files
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

## Prevention

Any package removed from Colab's base image must be explicitly installed in the Requirements cell.
