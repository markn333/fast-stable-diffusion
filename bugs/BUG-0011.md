# BUG-0011: sentencepiece C拡張とPythonラッパーのバージョン不一致
- 報告日: 2026-07-25
- ステータス: 完了
- 重要度: 高

## 現象

AUTOMATIC1111 WebUI 起動時に以下のエラーが発生し、起動が中断される。

```
AttributeError: module 'sentencepiece._sentencepiece' has no attribute 'delete_ImmutableSentencePieceText_ImmutableSentencePiece'
...
RuntimeError: Failed to import transformers.models.auto because of the following error (look up to see its traceback):
module 'sentencepiece._sentencepiece' has no attribute 'delete_ImmutableSentencePieceText_ImmutableSsentencePiece'
```

エラーの伝播経路:
`webui.py` → `initialize.imports()` → `pytorch_lightning` → `torchmetrics` → `transformers` → `sentencepiece`

## 原因

Google Colab のベースイメージ更新により、`sentencepiece` の Python ラッパー（`__init__.py`）と
C 拡張モジュール（`_sentencepiece.so`）のバージョンが不一致になった。

Python ラッパーが存在しないシンボル（`delete_ImmutableSentencePieceText_ImmutableSentencePiece`）を
C 拡張に対して呼び出そうとするため `AttributeError` が発生する。

## 処置内容

Requirements セルに `sentencepiece` の強制再インストールを追加した。
`--force-reinstall` により Python ラッパーと C 拡張の両方が同一バージョンで再インストールされ、
バージョン不一致が解消される。

```python
!pip install --force-reinstall sentencepiece -qq
```

### 変更ファイル
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements セル（#VSC-fb11748d）

## 再発防止策

Colab のベースイメージ更新のたびに sentencepiece のバージョン不一致が起きる可能性がある。
`--force-reinstall` により毎回クリーンに再インストールすることで自動的に回避できる。
