# BUG-0011: sentencepiece C extension and Python wrapper version mismatch
- Date: 2026-07-25
- Status: Resolved
- Severity: High

## Symptom

AUTOMATIC1111 WebUI fails to start with the following error:

```
AttributeError: module 'sentencepiece._sentencepiece' has no attribute 'delete_ImmutableSentencePieceText_ImmutableSentencePiece'
...
RuntimeError: Failed to import transformers.models.auto because of the following error (look up to see its traceback):
module 'sentencepiece._sentencepiece' has no attribute 'delete_ImmutableSentencePieceText_ImmutableSentencePiece'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `pytorch_lightning` → `torchmetrics` → `transformers` → `sentencepiece`

## Root Cause

A Google Colab base image update caused a version mismatch between the `sentencepiece` Python wrapper (`__init__.py`) and the C extension module (`_sentencepiece.so`).

The Python wrapper attempts to access a symbol (`delete_ImmutableSentencePieceText_ImmutableSentencePiece`) that does not exist in the installed C extension, resulting in an `AttributeError`.

## Fix

Added a force-reinstall of `sentencepiece` to the Requirements cell. Using `--force-reinstall` ensures both the Python wrapper and C extension are reinstalled from the same version, resolving the mismatch.

```python
!pip install --force-reinstall sentencepiece -qq
```
