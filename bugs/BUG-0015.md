# BUG-0015: ModuleNotFoundError: No module named 'kornia'
- Date: 2026-08-24
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'kornia'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `paths.py` → `sgm` → `sgm/modules/encoders/modules.py` → `import kornia`

## Root Cause

A Colab base image update removed `kornia` from the pre-installed packages.

## Fix

Added `kornia` to the Requirements cell (combined with `pyngrok` and `pytorch_lightning`):

```python
!pip install pyngrok pytorch_lightning kornia -qq
```

## Changed Files
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

## Prevention

Any package removed from Colab's base image must be explicitly installed in the Requirements cell.
