# BUG-0018: ModuleNotFoundError: No module named 'git'
- Date: 2026-08-24
- Status: Resolved
- Severity: High

## Symptom

WebUI fails at startup with:

```
ModuleNotFoundError: No module named 'git'
```

Error propagation path:
`webui.py` → `initialize.imports()` → `shared_init.py` → `shared.py` → `shared_items.py` → `script_callbacks.py` → `extensions.py` → `gitpython_hack.py` → `import git`

## Root Cause

A Colab base image update removed `gitpython` (which provides the `git` module) from the pre-installed packages.

## Fix

Added `gitpython` to the Requirements cell:

```python
!pip install pyngrok pytorch_lightning kornia open_clip_torch diskcache gitpython -qq
```

## Changed Files
- `fast_stable_diffusion_AUTOMATIC1111.ipynb` — Requirements cell

## Prevention

Any package removed from Colab's base image must be explicitly installed in the Requirements cell.
