# BUG-0003: sd_emphasis.py でテンソルデバイス不一致エラー
- 報告日: 2026-04-29
- ステータス: 完了
- 重要度: 高

## 現象
AUTOMATIC1111 起動時にモデルロードが失敗する。

```
RuntimeError: Tensor on device cuda:0 is not on the expected device meta!
```

エラー箇所:
```
File ".../modules/sd_emphasis.py", line 42, in after_transformers
    self.z = self.z * self.multipliers.reshape(self.multipliers.shape + (1,)).expand(self.z.shape)
```

## 原因
PyTorch 2.10.0 の内部ディスパッチ変更により、`torch._refs` / `fake tensor` 経由で乗算が実行される際に、`self.multipliers`（CPU テンソル）と `self.z`（cuda:0 テンソル）のデバイスが一致しないと `meta` デバイスの不整合を起こすようになった。

具体的には `torch._compile` → `torch._dynamo.eval_frame` → `torch._prims` のパスを経由し、meta テンソルとの device チェックが発動する。

## 処置内容
Start セル (`PjzwxTkPSPHf`) に下記 sed パッチを追加:

```bash
!sed -i 's@self\.multipliers\.reshape@self.multipliers.to(device=self.z.device, dtype=self.z.dtype).reshape@g' \
  /content/gdrive/$mainpth/sd/stable-diffusion-w$blsaphemy/modules/sd_emphasis.py
```

`self.multipliers` を乗算前に `self.z` と同じ device・dtype に明示的に変換することで解決。

変更ファイル: `fast_stable_diffusion_AUTOMATIC1111.ipynb`（Start セル）

## 再発防止策
- PyTorch メジャーバージョンアップ時は `sd_emphasis.py` 等のテンソル演算コードを重点確認する
- Environment Check セルで PyTorch バージョンの変化を検知できる体制は整っている
