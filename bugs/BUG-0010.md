# BUG-0010: aiohttp FormData keyword argument error
- Date: 2026-04-30
- Status: Resolved
- Severity: Medium

## Symptom
```
TypeError: FormData.__init__() got an unexpected keyword argument 'default_to_multipart'
```
ComfyUI startup aborted immediately after model loading.

## Root Cause
The pre-installed `aiohttp` in Colab runtime was older than required by ComfyUI.
The `default_to_multipart` parameter was introduced in a newer version of `aiohttp`, so calling code inside ComfyUI raised a `TypeError`.

## Fix
Added `aiohttp -U` to the Requirements cell (`pip install -U aiohttp`) to upgrade to the latest compatible version.
